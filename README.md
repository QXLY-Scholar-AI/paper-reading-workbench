# Paper Reading Workbench · 论文精读工作台

在 Codex 中读论文，在本地网页中对照原文、查看插图和整理引用。AI 负责阅读与写作；网页用于浏览结果、批注和保存材料，不另行调用模型。


Skill 曾用名：`jzks-pdf-viewer`

## 从哪里开始

将完整 Skill 包交给 Codex 安装，保留 `SKILL.md`、`scripts`、`assets`、`references` 和 `modules`，不要只复制规则文件。分发包不包含本机路径配置、R 运行时或用户论文库；Codex 会在实际环境中选择可用路径。安装后在 Codex 聊天中提供 PDF，选择以下任务。

| 任务 | 可以直接发送的指令 | 工作方式 |
| --- | --- | --- |
| 全文精读 | 请使用 paper-reading-workbench 精读本文献。 | 直接完成精读，生成并打开HTML网页、保存入库并给出链接；附加功能不阻塞基础交付。 |
| 插图分析 | 请使用 paper-reading-workbench 分析本文献的插图。 | 直接开始，结合全文、图注和上下文理解，再查数据、保存并验证 R 代码。 |
| 参考文献 | 请使用 paper-reading-workbench 查询本文献的参考文献，仅提供链接，不批量下载。 | 提取完整列表，核对题录身份，区分已核验与待确认入口。 |
| 论文初稿（Beta） | 请以这篇精读文献为核心之一，结合补充材料，围绕【填写实际课题】启动中文论文写作。 | 在 Codex 中逐步讨论材料、课题、研究问题、可行性、大纲、起草与修订。 |

**所有功能默认交付网页：**精读、插图分析、参考文献查询及写作阶段成果都会保存、打开对应网页并提供HTML链接，不需要再次提醒。初稿阶段页面标明当前进度，真正形成稿件后才显示为已生成。删除或清理历史后自动更新论文库。

**精读调用：**只需说“精读这篇论文”，完成后就会生成并打开HTML阅读器、保存到论文库并直接给出链接，无需再提醒生成或打开网页。只说“打开工作台”时，直接打开既有论文库首页。论文库每篇论文的“未生成”按钮会提供已填好标题、PDF 指纹和库内原文路径的指令，复制到 Codex 聊天发送即可。用户无需额外登录命令行模型，也无需从网页启动 AI 任务。

## 四类成果

### 文献精读

围绕研究问题、方法、结果、证据与结论、局限与启发，形成连贯的五步精读。正文和批注按观点来源区分“作者报告”与“AI解读”：原作者的重要观点、方法、结果和结论即使由AI归纳仍属于作者报告，额外的解释、质疑、推断和建议才属于AI解读，混合段落拆开；“作者报告”标签采用橙色底纹，文字沿用当前主题颜色。标题、作者、单位等只放基本信息，不作精读证据。原文摘录与点评标签分开显示。证据编号连接到原 PDF 的物理页和原文高亮；无法唯一定位的引句会标记出来，不伪造高亮。原文区域支持滚轮翻页：到页底继续向下滚进入下一页顶部，到页顶继续向上滚返回上一页底部；保留页码输入和翻页按钮，滚动不会带动左侧精读或右侧批注栏翻页，并设置短暂间隔避免连跳。阅读器支持筛选、缩放、专注模式、个人批注与勾画，并提供 Markdown、批注 PDF 和笔记 JSON。

### 插图画廊

紧凑缩略图总览，点击查看原图、R 重绘及上下文，支持上一张/下一张、收藏、选图要求汇总和材料下载。每图固定包含三部分：

1. **插图解析**：解释变量、统计定义、分组、研究含义及证据边界。
2. **数据来源**：说明数据实际是否取得、入口及访问状态、使用了报告数值还是图像数字化。
3. **研究应用建议**：针对该图给出适用研究情景、数据结构、比较方式、迁移示例及限制，不套用“替换 CSV”的通用说明。

R 的数据模式明确区分原数据、论文报告数值、图像数字化近似和模拟模板。只有实际运行成功并检查产物后才标记“已运行”；数字化近似与模拟图不能称为原始数据复现。没有 R 环境时保存代码并如实标为未运行。

精读与画廊按同一 PDF 联动：

| 已完成成果 | 点击图或原文链接的效果 |
| --- | --- |
| 仅精读 | 点击原文插图，提示“请先完成插图分析”。 |
| 仅画廊 | 打开相同样式的原文阅读器，只有插图语境标注，不填充虚构精读。 |
| 精读与画廊均有 | 原文插图与画廊详情双向跳转；语境引句可以返回对应页和标注。 |

### 参考文献链接

仅提供合法文章、公开 PDF、机构仓储或出版社入口，不批量下载论文。

- **已核验**：题录身份与本次可读页面相符；PDF、全文、摘要等材料类型分别标明。
- **橙色待确认**：题录身份已匹配，但本次访问受到登录、验证码或空壳页面限制。保留实际找到的链接，提示“题录身份已匹配；本次可读页面访问受限或返回验证码/空壳，尚未输出为已核验入口。建议您先行确认。”用户可通过学校账户等自行确认。
- **红色未找到信息**：检索后未匹配到有效信息；不编造链接。

复制链接或选中文献作为补充材料时保留核验状态。全文、摘要、简介与题录的证据级别不能混用；只有题录时不能据此编写研究发现。

### 论文初稿（Beta）

入口只锚定一篇核心文献，不会凭一篇论文自动拼整稿。包内完整保留 `academic-writing-zh`，来源版本见 `modules/academic-writing-zh-provenance.json`。

在 Codex 中按材料清点→主题与研究问题→补充证据与可行性→讨论确认论证大纲→按确认范围起草→评审修订推进。已确认环节可复用；证据不足不能硬写。占位课题未替换时提醒“请填写课题！”。实际产出初稿后，才保存 Markdown、网页、材料账本和适用的有来源插图，并归入论文库。网页主要用于对照稿件与引用依据。专门的评审意见勾画模块尚未交付。

## 论文库、主题与删除

原 PDF 与成果以磁盘文件保存。不同 PDF 按内容指纹分开；同篇新增成果增加版本，新增论文不会覆盖旧论文。首页、精读、画廊和参考文献等结果页共享日间/夜间模式，精读页的切换按钮位于顶部工具栏；笔记、复制、删除等弹窗不额外放置主题按钮。

每篇论文右下角有红色“删除”按钮，可选择精读、画廊、参考文献、初稿，或全部删除。所选类型会从**本篇所有保存版本**中移除，文件通过 Windows 原生接口移入**系统回收站**，没有二级应用回收站，也没有永久删除兜底。其他成果会继续保留并更新互相跳转的入口。全部删除包括库内原 PDF 副本，不影响库外原始文件。

删除弹窗还提供“删除历史版本”：只保留最新一个版本，各类成果的最新内容汇入该版本，旧版本移入系统回收站；最后一次只保存了部分模块也不会丢失其他模块的最新成果。

删除需要本机论文库服务；由 Codex 使用包内 `scripts/library_server.py` 打开，仅监听本机。离线 HTML 仍可查看，但无法直接操作系统回收站。服务校验请求来源与令牌；回收失败时显示错误。操作前的临时准备目录不是回收站；异常中断时可能保留待恢复材料。

删除磁盘成果不会擦除浏览器中已有的笔记或用户另行导出的备份；系统回收站中的旧材料仍可由用户自行恢复。

## 保存与备份

复制整个“论文精读库”文件夹，包括 `library.json`、`index.html` 和 `papers`。个人勾画、纠正和收藏保存在浏览器中，请先导出 JSON，再与论文库一起备份。换浏览器、换网址、清缓存前尤其需要导出；不承诺浏览器缓存永久可靠。

本地生成器不上传 PDF、不调用模型；文献检索会访问外部学术站点。分享结果 HTML 也会分享其内嵌论文与内容，请按材料权限使用。

## 环境与文件结构

- 生成器：Python 3.10+、PyMuPDF（见 `requirements.txt`）；查看结果使用现代浏览器。
- R 重绘：需要实际可用的 Rscript；没有则保存代码并标记未运行。
- 系统回收站：当前实现面向 Windows，调用系统组件，不额外安装回收站软件。
- 扫描 PDF：需要可定位的 OCR；缺少 OCR 时不能承诺逐句原文高亮。

```text
SKILL.md                  调用规则
references/               精读、画廊、链接和写作规范
assets/                   阅读器、画廊、论文库与公共主题
scripts/                  生成、入库、备份及本机服务
modules/academic-writing-zh/ 内置中文写作 Skill
modules/academic-writing-zh-provenance.json  来源记录
tests/                    合成材料回归检查
```

典型结果包含 `reading.json`、`paper-card.md`、`annotated-paper.pdf`、`gallery.html`、逐图 R/数据/运行记录、`references.html`，以及真实稿件产出后的 `manuscript.html`。不会把未完成模块标成已完成。
