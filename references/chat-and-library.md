# 聊天调用与长期论文库（现行流程）

2026-10-22用户明确调整：不用新建按钮、系统文件选择、多选弹窗或网页自动驱动Codex；从当前Codex聊天提供PDF和自然语言指令。不要让用户登录命令行、配置模型或启动后台代理。网页用于查看、批注、收藏，不是模型执行器。

## 所有模式的默认交付（硬性规定）

精读、插图分析、参考文献查询、论文写作各阶段有可展示成果时，统一保存、打开对应HTML并直接提供链接，不等待用户另说生成网页或索要链接。仅打开工作台则直接给既有首页。删除与历史清理后自动刷新首页。初稿各阶段网页准确标注进度，不能绕过必要的选题/大纲讨论，也不能将计划或材料清单冒充完成稿件。

## A 全文精读

触发语示例：“请使用这个skill精读本文献”“精读全文”。直接读取全文及关键图表，按deep-reading.md完成五步解读与证据定位，生成真实HTML、入库、自动打开并交付可点击链接。这些属于精读指令的默认交付，不等待用户另说“生成/打开网页”。

2026-10-22最新硬性规定覆盖旧“先读后问”的流程：不得把可选插图分析/参考文献查询的询问挡在基础精读交付之前。未指定的附加模块不默认启动；已经明确要做的模块按范围继续，不重复确认。

只要求“打开工作台”时，直接打开既有论文库首页并给链接；如明确要看某篇论文，则打开其已有结果。缺少必要输入或文件确实无法读取时如实说明，不造空页面或不存在的链接。

## B 插图分析

触发语示例：“请使用这个skill分析本文献的插图”。直接开始，不追问A流程的可选项。不只看图片：先读全文，再逐图核对方法、图注、图引用上下文、结果含义和数据；按figure-gallery.md提取、查数据并生成R。可以内部保存阅读记录，不强制额外交付完整五步精读，不默认额外做参考文献查询。

## C 参考文献链接

用户单独或追加选择时读取reference-links.md：提取原列表并检索、核验合法公开入口，只交链接，不批量下载。不得把C当作A/B默认必做项。

## D 论文初稿 beta

明确要求围绕课题、以精读文献为核心写初稿时，读取 manuscript-beta.md 和包内 academic-writing-zh 规则。补充文献可来自用户文件/链接或参考文献页勾选后复制的指令。网页只复制选择，不驱动模型；入口只锚定当前论文为核心材料之一；在Codex聊天中逐步推进主题、研究问题、材料与可行性、大纲确认、起草和评审修订，不凭一篇文献直接生成整稿。真实稿件产出后才归档；网页侧重稿件与文献依据对照。首页标签为“论文初稿（Beta）：未生成”，产出后变为结果链接。

## 不覆盖的存档流程（所有模式）

1. 读取Skill目录local-runtime.json中的library_root；没有则用本次项目可写位置的“论文精读库”，记录并继续沿用。优先复用既有library.json，不能每次随意新建另一份论文库。不要把仓库模板当用户成果目录。
2. 先在本次日期/任务命名的新工作目录生成、核对结果。不要向上篇论文结果目录生成，不要反复向同一个demo目录写新论文。用于同篇修订的目录也要新建，先前文件留存。
3. 用 `python scripts/paper_library.py register --pdf 原文.pdf --result 新结果目录 --library 论文精读库` 入库。它按PDF完整SHA256分论文、按时间与随机ID增加不可变版本，并更新全库首页；源目录只读复制，不删除任何旧论文或旧成果。同篇只新增画廊时，旧精读入口仍保留。不同PDF修订版按不同指纹分别存档。
4. 检查返回的论文ID、版本及首页，核对上一论文链接仍可打开。生成器创建的文件不等于语义检查已完成；入库只证明文件对应和保存，不证明分析正确。
5. 完成后自动用应用文件/浏览器打开新结果或论文库首页，并提供真实路径链接。没有对应应用工具时交付可直接打开的HTML文件。用户只说精读时不让其手工输入脚本或路径。

## 数据持久性与备份

论文PDF、精读、图、R、源数据及网页在磁盘文件夹中长期保存，关闭浏览器不删除。备份整个论文库即可离线浏览；register保留原PDF，分享前提醒材料权限。

个人收藏、勾画和纠正在浏览器本地保存，不等于写回生成的文件。换浏览器/网址、清缓存前，分别导出笔记/收藏JSON并与论文库一起备份；同一论文通过导入JSON迁移。不要声称缓存永久可靠或所有笔记已自动存盘。网页备份入口给普通用户清楚说明，不能伪装成已备份。

可由宿主运行 `paper_library.py backup --library 论文精读库 --out 新备份.zip`；不覆盖旧ZIP，输出必须放论文库外，避免递归。

首页按论文显示入口：已有成果直接打开；“未生成”按钮打开任务指令弹窗，自动填写该论文标题、PDF指纹与库内原文路径，提示复制后粘贴到Codex聊天。初稿指令保留填写课题提醒及可行性评估。不再显示顶部通用复制按钮。首页与弹窗采用暖灰/米白/蓝灰，夜间为柔和灰蓝。

## 日夜模式与用户主动删除

各生成页面使用page_theme.py嵌入同一主题，沿用paper-library-theme存储键；原始科研图片不反色。旧版本文件保留原样，需要新版主题时生成新版本，不批量改写旧成果。

论文库首页每篇论文右下角提供红色删除入口，可选精读/画廊/参考文献/初稿或全部，范围为同篇所有版本。只在用户实际点击提交或明确要求删除后执行，不因测试删除真实论文。通过library_server.py仅监听127.0.0.1提供本机服务；宿主负责打开服务，不要求用户配置命令行模型。POST使用同源与令牌校验。

library_delete.py调用Windows系统回收站，绝不以永久删除作为回收失败的替代；仅在临时副本中清理已选类型，回收原目录并保留其他成果。全部删除包括库内原文副本，不能触碰库外PDF。删除精读而保留画廊时重建只有图标注的原文窗口；删除画廊而保留精读时恢复请先完成插图分析的提示。删除不清理浏览器缓存、独立备份或系统回收站旧文件；失败如实报告。无结果时不提供虚构成果入口。

2026-10-22预览调整：删除弹窗取消日夜切换；新增独立按钮“删除历史版本”，说明只保留最新版本。各类最新成果汇入同一个保留版本，其余旧版本移入系统回收站；不因最后一次只新增参考文献而丢失精读或画廊。合成材料9项删除测试与UI/主题逻辑检查通过。尚未清理用户真实论文的历史记录，等待用户页面操作；按用户要求暂不封包。
